# 短视频现场拍摄排期 Skill

把一批短视频脚本整理成简洁、可执行的现场拍摄顺序：**逐画面拆分，口播集中拍，同类镜头一起安排，每条素材独立录制。**

适合产品短视频编导，以及需要批量拍摄多条视频的团队。脚本不限于某种产品、场景或演员人数，示例全部虚构。采用 [MIT 许可证](LICENSE)。

## 解决什么问题

- 一行脚本可能包含多个画面，原表写的镜头数不能直接相加。
- “集中拍”节省换机位和布光时间，不能擅自减少素材条数。
- 显式口播、边演示边讲解集中收音，旁白不会自动变成口播。
- 可直接拍、条件实拍、AI和外部素材分别统计，数量不明的残句明确标注。
- 根据开箱、安装、完整外观、拆件、演员和道具的实际依赖排序。
- 输出一张简版 Excel；需要时再导出 PDF 并检查文字、字体和分页。

这是给 AI 助手使用的工作流技能，**不是独立的 Excel 自动解析软件**。自然语言拆分和排拍需要助手判断；附带 Python 工具只核验台账结构和计数，不负责自动判断镜头语义。

## 安装与使用

将整个仓库文件夹命名为 `short-video-shoot-planner`，放进支持 `SKILL.md` 的助手技能目录。Codex 用户可运行：

```bash
git clone https://github.com/ChanEee-niubi/short-video-shoot-planner.git \
  "${CODEX_HOME:-$HOME/.codex}/skills/short-video-shoot-planner"
```

如果目标目录已存在，请先确认它的内容，不要覆盖已有版本。安装后重新打开会话，在技能列表中查找“短视频拍摄排期”。其他助手是否支持自动发现技能，请以其说明为准。

使用示例：

```text
使用 $short-video-shoot-planner，分析这五份脚本。
卧室场景，一名女生，素材不能重复，口播放一起拍。
给我一个简洁 Excel：第一步拍什么×几条，第二步集中拍什么，哪些需要单拍。
```

后续可以直接说：“这五条也安排一下，继续沿用上面的规则。”

仅转换文件：

```text
使用 $short-video-shoot-planner，把这个 Excel 转成 PDF。
保留内容，检查长文本和分页，不改动原文件。
```

助手需要能读取附件、生成和渲染表格／PDF；具体工具由运行环境提供。本仓库不安装办公软件、不携带字体、不调用外部服务。校验器只依赖 Python 3.9+ 标准库。

## 输出长什么样

以下为虚构示例：可直接拍 **6条**＋条件实拍 **1条**＝计划实拍 **7条**，另 AI **1条**。

| 顺序 | 集中拍什么 | 条数 | 提醒 |
|---|---|---:|---|
| 第一步 | 对镜口播×2 | 2 | A、B分别录制，集中收音 |
| 第二步 | 面料特写×2＋按压回弹×2 | 4 | 同机位也要分别录制四条 |
| 第三步 | 底面展示×1 | 1 | 条件镜头：需要搬运人手，单独拍 |

上述7条不含 NG 重拍。真实项目条数必须来自逐画面台账，不能照搬示例。

## 校验与测试

在仓库目录中执行：

```bash
python3 scripts/validate_plan.py references/example-plan.json
python3 -m unittest discover -s tests -v
```

校验器只读取给定 JSON，成功输出统计并返回0，错误返回1。它会检查：

- 画面 ID 唯一，源行关联一致，每个画面在源行清单中恰好出现一次。
- 每个实拍画面恰好分配到一个拍摄组，不遗漏、不复用。
- AI／外部素材不混入实拍组，条件镜头必须写明条件。
- 口播集中在一个阶段；无法集中时必须提供具体解释。
- 分组与分脚本统计使用同一份已核验台账，保留未定源行。

程序无法发现“源行清单本身漏了一行”或“自然语言拆错”。使用者仍须对照原文件逐行复核。组名中的文字数量、最终 Excel 公式和视觉版式也需要导出后检查。
