# Excel 转 PDF（按需）

适用于拍摄表及用户单独指定的 Excel；转换不授权重写脚本、重算镜头或覆盖原文件。

1. 检查所有工作表、实际有值范围、隐藏行列、合并单元格、图片、公式缓存、纸张与打印区域。长文本可能被源表行高遮住，不仅凭截图判断完整性。默认遵循原表可见性，影响“全部内容”要求时明确范围。
2. 优先现有办公应用／转换器的原生导出，保留样式并控制纸张方向和缩放，不把宽表硬缩到不可读。不要未经说明安装系统级软件。
3. 原生导出截断或严重分页时，可在副本调整打印设置，或按原列重新分页；说明保留内容、调整行高／分页，不声称完全保留原版式。
4. 使用可嵌入且覆盖中文的字体。仅声明 CID 字体可能在其他设备缺字，优先嵌入并检查特殊符号；不要将本机字体上传开源仓库。
5. 每页重复必要表头，避免孤立标题、内容切断、声画对应错位、空白页或越界。公式无缓存时用合适引擎计算，不把未知值变成零。
6. 将源表每个非空显示文本与 PDF 提取文本对照，可规范化空白；图片、图表、不可提取文字单独视觉核对。提取通过不等于视觉通过。
7. 渲染所有页面，查看全页总览并放大密集页、跨页边界和复杂合并单元格页；检查字号、中文、边界和分页。修复后复查受影响页。
8. 另存 PDF，保留 XLSX；交付文件链接、页数和实际限制。没有验证不能声称内容完整或格式无误。

按环境选用原生办公导出／LibreOffice、ReportLab、pypdf／pdfplumber、Poppler 等，不要求全部安装；有平台 PDF 技能时遵循其要求。重排只适用于确认能够保真处理的内容；复杂图表或嵌入对象无法保留时明确限制。
